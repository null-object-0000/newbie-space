# 每日一题 · 文章转口播视频

用 Remotion 把 `src/content/posts/daily-2026-03-04.md`（Java 代码是怎么运行起来的？）做成**无声幻灯片视频**，方便你口播时按页暂停，或导出成图片放进 PPT 手动翻页。

**画布尺寸**：1080×1920（抖音竖版 9:16）。

## 安装

```bash
cd remotion-daily-video
npm install
```

## 方式一：生成无声视频（口播时暂停）

每页默认 **8 秒**，共 9 页（约 72 秒）。录屏时在每一页暂停，口播完再继续播放即可。

```bash
npm run render
```

输出：`out/daily-2026-03-04.mp4`

**之后要改每页时长**：告诉我每页你实际口播的秒数，我可以帮你改 `ArticleSlides.tsx` 里的 `SEC_PER_SLIDE`，或改成每页不同时长。

## 方式二：导出每页为 PNG（做 PPT 手动翻页）

导出 9 张图，放进 PowerPoint / Keynote 里手动翻页录屏。

```bash
npm run export-slides
```

输出在 `out/slides/` 下，按帧导出的 PNG（对应 9 页）。可重命名为 `slide-1.png`～`slide-9.png` 再插入 PPT。

## 预览与微调

```bash
npm start
```

会打开 Remotion Studio，可预览时间轴、改每页时长或文案，确认后再执行上面的渲染命令。
